# 策略金库页面样式

本目录保存 `/vault` 及独立存赎路由的 CSS。各页面与区块组件从这里导入样式，并使用全局主题颜色变量。组件位于[页面目录](../README.md)，接口请求与类型位于[接口目录](../../../features/vault/api/README.md)。

| 样式文件 | 对应区域 |
| --- | --- |
| [vault-page.css](vault-page.css) | 主页两栏布局、操作入口、选择器及独立操作页返回入口 |
| [vault-overview-cards.css](vault-overview-cards.css) | 右栏资产估值与即时赎回资金来源 |
| [vault-transaction.css](vault-transaction.css) | 独立页的填写、复核、Phantom 确认和回执状态 |
| [vault-position.css](vault-position.css) | 我的金库份额 |
| [vault-nav-history.css](vault-nav-history.css) | 每份净值走势区块、查询状态和分页控件 |
| [vault-nav-chart.css](vault-nav-chart.css) | 图表、坐标轴、观测点和详情 |
| [vault-recent-activity.css](vault-recent-activity.css) | 最近金库交易标题、入口及查询状态 |
