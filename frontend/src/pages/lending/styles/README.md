# 借贷页面样式

本目录存放 [借贷页面](../README.md) 专用 CSS，复用全站主题变量。

| 样式文件 | 对应区域 |
| --- | --- |
| [lending-market.css](lending-market.css) | 市场首页布局、借款和出借入口、清算入口、市场选择及查询状态 |
| [lending-pool-metrics.css](lending-pool-metrics.css) | 资金池观测时间与实际指标行 |
| [lending-position.css](lending-position.css) | 「我的借款」和「我的出借」的仓位布局、指标行与查询状态 |
| [lending-supply-operation.css](lending-supply-operation.css) | 出借和提取操作页共用的输入表单、金额与份额核对、交易结果 |
| [lending-borrow-operation.css](lending-borrow-operation.css) | 四类借款操作的金额输入、核对与交易结果 |
| [lending-borrow-activity.css](lending-borrow-activity.css) | 「最近借款交易」的列表、确认状态和浏览器链接 |
